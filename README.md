# نموذج متابعة فرص المبيعات

واجهة عربية RTL لتسجيل جهات تراجعينها يدوياً وتنظيم حالتها وموعد المتابعة. تتضمن قوالب قابلة للتعديل ومسودات للمراجعة والنسخ فقط. لا يوجد بحث مباشر أو اتصال خارجي أو إرسال رسائل.

## التشغيل محلياً

1. نزّلي ملفات المشروع العام إلى الجهاز.
2. افتحي الطرفية داخل مجلد المشروع وشغّلي `python3 -m http.server 8000`.
3. افتحي عنوان الخادم المحلي الذي يظهر في الطرفية، من متصفح الجهاز نفسه. أوقفي الخادم بـ `Ctrl+C`.

لا يحتاج المشروع حزم أو مفاتيح API. المستودع عام حسب اختيارك، لكن التطبيق لا يُنشر أو يُستضاف هنا.

## الاستخدام والخصوصية

أضيفي السجلات يدوياً، ثم استخدمي البحث والحالة ومرشح المتابعة المستحقة. يمكن تعديل السجل أو حذفه. عدّلي القالب واحفظيه، ثم اختاري جهة لإنشاء مسودة ومراجعتها وتعديلها ونسخها. لا يوجد إرسال من داخل التطبيق.

السجلات والقوالب محفوظة في `localStorage` بملف المتصفح على الجهاز الحالي فقط. لا توجد مزامنة أو نسخة احتياطية أو تصدير، وقد تضيع البيانات عند مسح بيانات المتصفح أو تغيير الجهاز. استخدمي بيانات افتراضية فقط، ولا تدخلي بيانات عملاء فعلية أو معلومات سرية أو كلمات مرور أو مفاتيح.

## الاختبارات والحدود

بعد تثبيت Node.js، شغّلي `node --test tests/app.test.js` للاختبارات الأساسية دون حزم إضافية. لا توجد اختبارات متصفح آلية؛ راجعي العرض على الهاتف والمتصفح المستهدف قبل الاستخدام.

النسخة تجريبية محلية: لا بحث مباشر، ولا حسابات أو مزامنة أو استيراد أو تصدير، ولا تكاملات أو إرسال أو نشر مستضاف.
